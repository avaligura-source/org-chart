# Org Chart Builder

Інтерактивна оргструктура: картки людей, звʼязки між ними, кількість тасок і юніти.

- **+ Людина** — нова картка (якщо виділена картка — стане її підлеглим).
- Потягни **синю точку** під карткою на іншу картку — створиться звʼязок. Відпусти в порожньому місці — новий підлеглий.
- Клік по звʼязку + `Delete` — видалити звʼязок.
- **Shift+клік** — виділити кілька карток → **+ Юніт**.
- Тягни за назву юніту — рухається вся група.
- Кількість тасок — `−`/`+` на картці або в панелі праворуч.
- `Cmd/Ctrl+Z` — скасувати.

## Збереження
Усі зміни автоматично зберігаються в браузері (localStorage).
Щоб зберігати в репозиторій (і бачити з будь-якого пристрою): **☁ GitHub** → вставити fine-grained token
з правом *Contents: Read and write* лише на цей репозиторій. Дані пишуться у `data/org.json`.
